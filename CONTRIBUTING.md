# Contributing

Thanks for helping improve BrutalKit.

- Use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Keep primitives small and composable.
- Prefer semantic HTML and keyboard-accessible behavior.
- Include reduced-motion behavior for animations.
- Document public classes and CSS tokens.
- Run `bun run build` and `bun test` before opening a pull request.
